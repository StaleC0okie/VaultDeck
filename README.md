# VaultDeck


Buscador de cartas de Magic: The Gathering con creador y guardado de mazos.

# Funcionalidades
- Búsqueda de cartas en tiempo real (Scryfall API)
- Creación y edición de mazos
- Guardado de mazos (Django REST Framework)

# Tecnologías
React · Django · Django REST Framework · Bootstrap · Scryfall API
